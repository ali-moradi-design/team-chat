# Team Chat

Slack-style team chat built with Node.js, Express, Socket.IO and MongoDB.

> The code in `apps/server` and `apps/web` started as a plain copy (without
> history) of two earlier practice repos by the same author:
> [`nodejs-chat-socket`](https://github.com/ali-moradi-design/nodejs-chat-socket) and
> [`nodejs-chat-web`](https://github.com/ali-moradi-design/nodejs-chat-web).
> It is being restructured into this monorepo.
